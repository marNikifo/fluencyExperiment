This folder contains anonymized data for the experiments described in [Nikiforova (2025)]([url](https://scholarworks.umass.edu/entities/publication/fe445efd-8fb8-47d9-a901-58a21f426b2b)).

The "merged_means" file includes the average attractiveness ratings and response time for each participant, while "merged_dat" includes response data for each individual trial.
